The ProGit Architecture Edge

A high-performance pure-Go modular monolith with zero external runtime dependencies.

Single Static Binary
Pure Go backend with React 19 SPA assets embedded via embed.FS. One compiled executable contains the web UI, REST API, Git engine, and SSH daemon.
Zero CGO Database
Powered by pure Go SQLite (modernc.org/sqlite) with Write-Ahead Logging (WAL) for single-node, and enterprise PostgreSQL clustering for HA multi-node setups.
Native SSH on Port 2222
Integrated pure-Go SSH server requires no host OpenSSH alterations, eliminating PAM security vulnerabilities, host key leaks, and complex port redirection headaches.
Full Git Smart HTTP
Native integration with git-upload-pack and git-receive-pack supporting fast packfile negotiation, shallow clones, and authenticated credential caching.
Real Git-Backed Wikis
Every repository includes an independent real Git wiki repo (repo.wiki.git). Clone, push, and edit offline via CLI or online with responsive markdown preview.
ProGit Pages (GitHub Pages)
Publish documentation portals, portfolios, and static web apps directly from gh-pages or main branch with automated Markdown rendering and access controls.

Enterprise Security & Compliance

Engineered from day one for zero-trust environments, financial institutions, and defense air-gapped enclaves.

Zero CGO Memory Safety
No external C libraries (libgit2, sqlite3.so). The Go runtime provides complete memory safety, eliminating buffer overflow CVEs common in legacy C codebases.
Enterprise SSO & SCIM
SAML 2.0 and OIDC integrations for Microsoft Entra ID (Azure AD), Okta, Ping Identity, and Google Workspace. Automated SCIM user lifecycle deprovisioning.
Comprehensive Audit Logs
Immutable audit trails tracking all logins, repository clones, pushes, token creations, and administrative actions. Real-time CEF/JSON streaming to Splunk or Datadog.
Branch Protection Rules
Enforce code review approvals, require status check passes, block force pushes, restrict branch deletion, and verify GPG commit signatures prior to merging.
Rootless Container Hardening
Pre-configured non-root user execution (UID 1000), read-only root filesystems, SELinux volume type enforcement (:Z), and minimal attack surface alpine base.
Air-Gapped Offline Licensing
Cryptographically signed Ed25519 offline license keys. Requires zero internet connectivity and zero telemetry phoning home to third-party verification servers.

5-Minute Instant Deployment

Validate ProGit on your own hardware or workstation right now with official multi-arch container images.

Production Podman / Docker Command linux/amd64 & linux/arm64 
podman run -d \
  --name progit \
  --restart=unless-stopped \
  -p 3443:3443 -p 3000:3000 -p 2222:2222 \
  -v progit-data:/data/db:Z \
  -v progit-repositories:/data/repositories:Z \
  -v progit-config:/data/config:Z \
  ghcr.io/sanjeevsenapati/progit:latest
1. Multi-Arch GHCR
Official OCI manifests for x86_64 and ARM64 (Apple Silicon, AWS Graviton).
2. Out-of-the-Box HTTPS
Pure-Go auto-TLS on port 3443 with instant HTTP redirect on port 3000.
3. Isolated Volumes
SELinux volume labels (:Z) keep SQLite and Git bare trees completely safe.
